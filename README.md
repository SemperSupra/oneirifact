# Oneirifact

**Dreams Made Digital**

Oneirifact is a procedural 3D creation and exploration project. Its goal is to make editable, reusable designs accessible through a browser and richer local applications.

## Release status

This is the public project home. The interactive browser preview is in preparation and is not yet available. No product binaries or engine source are distributed in this initial repository.

Verified releases will include their supported features, limitations, build and test instructions, and applicable licensing notices. Until a release is available, this repository makes no claim of product functionality.

Feedback and questions are welcome through the [issue tracker](https://github.com/SemperSupra/oneirifact/issues). Please do not include credentials, personal information, or confidential project files.
