# R245 actual activity consumer

This is an original authored kinematic prototype, consumed in actual Blender on public standard CPU GitHub Actions runners. It does not qualify human-motion realism, dynamics, footwear fit, anatomical completeness, organs, physiological joint limits, collisions, breathing, grip or dental contact.

The immutable base is R245 motion-core commit `b47efccadb6e939d396dc794859ac61e88e3dbd6`. The source is the admitted MakeHuman exterior and original 163-bone rig. Source geometry, topology and all packed normalized skin weights (up to nine influences) remain intact through export. Uniform stature variants change rest shape/bind before posing; the additional male-older case uses the actual R235 nonuniform donor morph and helper-refitted bind. An internal layer omission manifest is included in each case.

`prepare.py` verifies exact public source archives and creates a measured post-morphology bind. `witness.py` imports that source, uses separate native two-joint IK chains, and transfers whole thigh/shin and arm-segment transforms to the original split `01/02` bones. It never treats intermediate `.02` bones as extra anatomical hinges. Foot orientation and toe articulation preserve the original rest and inverse binds. Shoe support proxies contain fixed actual heel/forefoot geometry and a toe plate hinged at the measured source middle-toe joint. Actual evaluated sole face centroids, skin sole subsets, original-bone FK and intermediate parent-relative rotations are exported separately from compiler targets.

Standing, sit-to-stand, squat, walk, brushing and walk-plus-brushing composition receive every authored 24 fps sample. Sitting, crouching, jogging, running, showering and eating receive five critical samples each. Their between-key interpolation is explicitly unqualified. Receipt rows distinguish compiled, evaluated, rendered, saved and exported activities. The arm-neutral posture and facial task landmarks are authored proxies; source A-pose arms are not retained as a walking pose.

The .blend retains every original bone, named baked actions, separate construction IK controls, original consumer source text and scope notes. All keyframe interpolation is linear. The GLB contains unchanged source mesh/skin attributes plus observed original-bone animation tracks and rigid footwear children of the original foot/toe joints with exact inverse-bind offsets; source weights are never reduced by Blender's exporter. The chair and wrist-parented toothbrush exist in the .blend and renders; they are explicitly excluded from the GLB, whose per-clip prop visibility is not encoded.

Qualification compares actual skin with independently calculated full-weight LBS, replays the saved .blend, and reimports the baked GLB. Selected whole-skin and footwear samples include fractional-frame seeks. Full sampled actual FK/shoe observations are captured again after both saved-scene and GLB reimport. The independent stdlib critic runs against these observations, with analytic positive and negative controls. Numerical or contact failures remain in artifacts and do not suppress rendered evidence. Realism stays unqualified even if all bounded engineering gates pass.

The nine-case matrix is male/female × 1.55/1.85 m × flats/stilettos, plus the actual male-older morph in flats. Six stills/contact-sheet panels are rendered for every case; four representative cases additionally receive short actual walking, squatting and composed walking/brush MP4s. CPU rendering is deterministic source consumption, not generated illustration. Original source licenses/provenance accompany every product archive.
